📚 Micro Learning — HTML5 Fundamentals

01 — Structure

HTML5 pages use a clear document structure. Start with the document declaration, then organise content inside <html>, <head> and <body>.

<!DOCTYPE html>\n<html>\n<head>\n <title>My Page</title>\n</head>\n<body>...</body>\n</html>

02 — Semantic Content

Use headings, paragraphs, lists, images and links to communicate information clearly. The existing lab checks these requirements automatically.

<h1>My Topic</h1>\n<h2>About the Topic</h2>\n<p>My description...</p>

03 — Interactive HTML5

HTML5 provides useful form and data-display elements such as <meter> and <progress>.

<meter min="0" max="100" value="80"></meter>\n<progress max="100" value="70"></progress>

04 — Accessibility

Images should include meaningful alt text. This helps users understand image content when the image cannot be viewed.

<img src="photo.jpg"\n width="300" height="200"\n alt="Modern computer laboratory">
